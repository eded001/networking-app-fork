# networking-app
App de networking

# Inicialização

> Entre na pasta **app**

Comece instalando as dependências

```bash
npm install
```

Inicie o servidor Metro

```bash
npm start
```

Crie a build do app.

> Atenção: é importante estar com o celular conectado ou estar com o emulador ligado

*Para Android*

```bash
npx react-native run-android
```

*Para IOS*

```bash
npx react-native run-ios
```
